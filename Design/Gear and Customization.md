# Gear and Customization

## Base kit
Every diver starts with an editable base kit:
- Dive watch / computer
- Air tanks (3 loadout options with trade-offs)
- Flashlight (battery runs out)
- Mask
- Wetsuit
- Flippers
- Repair tape (duct tape, Flex Tape)
- Logbook and measuring tools (optional loadout)
- Lantern for bioluminescent creatures (purchasable)

## Pre-dive screen
- A default dive loadout screen where you edit everything before the run.

## Masks
- Different masks for different functions with trade-offs. Examples: a mask with a headlight, a mask that seals better against flooding.
- Masks can be built from components, including items found in the cave.
- The mask holds the HUD (see [[HUD, Watch and Waypoints]]).

## Wetsuits
- Different colors and designs.
- A drawing-based customization screen: intuitive and simple to use, but deep enough to make complex designs.

## Flippers
- Set flipper models to choose from.
- Shape, width, and similar properties customizable using tokens and money from dives.

## Upgrades between runs
- Larger tank capacity, better mask functions, more stamina, faster swimming, and other stats. Exact numbers later.

## Not a priority
- Detailed character faces or bodies. Gear, accessories, and skins matter more.
